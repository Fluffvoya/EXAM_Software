# 项目整体架构阐述
## 概述
- 平台：STM32f103c8t6。
- 语言：C++17，但由于单片机flash小，没有过多使用C++的高级特性（特别是模板相关的）。
- 开发工具链：使用STM32CubeMX创建工程与配置引脚，VSCode进行代码开发，OZone进行烧录与调试。
## 程序入口点
具体定义位于`application.cpp`中，含两个编译为C语言abi的函数，`start()`和`update()`。
### start()
负责初始化工作，并调用每个实现`Object`接口的对象的`start`函数。
### update()
每帧调用，所有的渲染工作，事件检测都在这里完成，同样会调用每个实现`Object`接口的对象的`update`函数。
## Object接口
接口定义了两个纯虚函数：`start`和`update`分别在开始和每帧更新时调用，负责对象的初始化以及渲染和事件监听。

除此之外接口中还有一个`active`属性，表示当前对象是否被启用。
## ObjectList
程序中所有的对象定义在这个类中，每个对象都是static的，即可以全局访问的。

> 更加通用的方式应该为该类提供一个全局的对象树，在运行时进行对象的创建销毁等，然后其他类根据名字或者ID等方式查找对象进行引用，但这种tree一父子关系在本程序中并不刚需，二需要用到复杂的数据结构如哈希表，单片机flash太小故未采用。

## 屏幕驱动
屏幕的引脚是在CubeMX中配置的，驱动由AI根据附件`OLED.h`和`OLED.c`改写成了CPP，并使用HAL库。

改写时我让AI添加了帧缓冲，为了防止后续渲染多个对象时闪屏。
